> **Deprecated.** This is goo classic, the first engine, frozen at commit 6fcca08 (branch `goo-classic`). It is not developed further. The kernel that replaces it is specified in the repository's root `SPEC.md`.

# Working on goo

- **Classic is frozen.** Change it only to keep it importable; its goldens (the still life, the pear and the recorded sessions) must stay bit-identical.

Read `classic/SPEC.md` first. It is the contract; the code implements it. `classic/SPEC.md` §15 says what is verified and what is not.

- Run `python -m pytest classic/tests -q` before and after any change to `goo/classic/`. All tests must pass. If another copy of goo is installed, put this repository's root on `PYTHONPATH` and check `goo.classic.__file__`.
- Never write colour or height into the World from a painter or study script. Move paint with tools; set up tests with `Canvas.add` (it books what it adds).
- A new law needs: a switch in `Canvas.L`, conservative form through the limiter (or an explicit ledger entry), a test that it is exactly zero when off, the same arrays windowed and whole-panel (`classic/SPEC.md` I8), and respect for the frisket (I9).
- A change to the engine that is not meant to change results must reproduce existing paintings bit for bit: hash `q`, every stratum, `kappa`, `store`, `zb` and the ledger for the half-scale still life and the pear before and after.
- Classic optics is the default and stays the default. Under it the still life, the pear and the recorded sessions must stay bit-identical; changing the default model, or classic's numbers, is the owner's decision. New optics goes behind `optics="v2"` (or a new model).
- Every optical number (in `PIGMENTS`, `goo.classic.optics.SPECIES` / `GROUNDS`, `goo/classic/data/optics.json`) carries its provenance: computed (source and licence), measured (cited), assumed or guessed. Ship only numbers computed from permissively licensed (CC0) data or goo's own guesses marked as such; read restricted references for sanity checks only and copy nothing from them. `optics.json` is regenerated by `classic/studies/optics_data.py`, never hand-edited.
- `goo.classic.data` imports nothing else from goo. The `goo.classic.matter` kernel (`dielectric`, `morphology`, `mie`, `response`, `mechanics`, `substance`, `laws`, `tables`) imports neither the canvas nor the tools; only `classic`, `phenotype`, `search` and `example` may touch the engine, through `PIGMENTS`, `Canvas.add` on scratch canvases and `Canvas.km_layer`, and must leave it as they found it. The engine reads nothing from either yet.
- Sensors take a `Surface` and nothing else from the World; make one with `Surface.from_canvas(cv)`. Keep ground truth beside a measurement, never inside it.
- A painter (`goo.classic.painter`, `goo.classic.palette`, `goo.classic.detail`) reads the canvas only through `reflectance()`, `fix`, `wait`, `step`, `W`, `H`. The studio may also read `sheen()`, `touch_dry()`, `finish()` and call `fork()`, `mask()`, `unmask()`. Both are enforced by tests with the canvas behind glass. Dryness is judged by trying `fix` (painters) or by sheen and `touch_dry` (studio), never by reading cure, water or thickness. A canvas handed to a painter needs a `cure_rate`.
- Tools write through the tool channel (`cv._q`, `cv._U`, `cv._V`), mark where they wrote, and multiply their contact by `cv._open`. Reading `cv.q`, `cv.kappa` or `cv.store` from outside the engine is allowed in tests and studies but makes the next step rescan the panel.
- Units are in `classic/SPEC.md` §2. Brush loads are in volume units (0.0156 µL each); a real brush holds thousands.
- Outputs go to `out/` (git-ignored). Figures worth keeping go to `classic/docs/`.
- This repository is public. Motifs and test data are generated in code or are goo's own paintings.
